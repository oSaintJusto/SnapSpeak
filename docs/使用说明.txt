SnapSpeak 使用说明
==================

一个很小的 macOS 小工具:划一下屏幕 → 认出文字 → 念给你听。
英文还能顺便显示中文翻译。


【安装】

1. 把这个文件夹里的 SnapSpeak.app 拖到「应用程序」里
   (拖到「用户」文件夹下的「应用程序」也行)

2. 第一次打开要右键点击 App → 选「打开」→ 再点「打开」
   为什么要这样:这个 App 是我自己打包的,没有苹果开发者签名,
   macOS 默认会拦。右键打开一次之后,以后双击就正常了。

   如果右键打开也不行,打开「终端」粘这一行回车:
   xattr -dr com.apple.quarantine /Applications/SnapSpeak.app

3. 打开后 App 不进 Dock,只在屏幕右上角的菜单栏出现一个蓝色声波图标。
   点它 → 「设置…」可以先看看。


【用法】

默认快捷键:Control + Option + S
(如果和你别的软件冲突,在设置里点快捷键那个方框,重新按一组即可,
 建议用 Control+Option 开头的组合,不容易冲突)

按一下 → 屏幕变十字 → 拉一个框 → 松手就念出来了。


【第一次会让你授权】

第一次按时,系统会弹「SnapSpeak 想要录制屏幕」。点「允许」。
如果点错了:系统设置 → 隐私与安全性 → 屏幕录制 → 勾上 SnapSpeak,
然后完全退出 App 重开。


【念英文时显示中文翻译(可选)】

需要自己去 platform.deepseek.com 申请一个 API Key(充值一点点就够用),
在「设置 → 英文翻译」里填进去,点「保存并测试」,显示「✓ Key 可用」就行了。

不填也能用,只是没有翻译。Key 存在 macOS 钥匙串里,不会写进配置文件。


【朗读时的小窗口】

底部会浮出一条:暂停 / 拖进度 / 钉住 / 关闭。

· 按住空白处拖动 —— 挪位置
· 拖右下角斜纹   —— 改大小
· 📌 钉住        —— 播完不消失,方便慢慢看译文
· 字号           —— 在设置里调(10~20)

位置、大小、是否钉住、字号都会记住。


【常见问题】

Q: 双击提示「无法打开,因为无法验证开发者」
A: 见上面第 2 步,右键 → 打开。

Q: 点了图标没反应 / 想知道哪里出错
A: 看日志:打开「终端」输
     tail -f ~/Library/Logs/SnapSpeak.log
   里面记录了启动、快捷键注册、每次取词的耗时和报错。

Q: 按了快捷键没反应
A: 多半是没给屏幕录制权限(见上面)。也可能快捷键被别的软件占了,
   去设置里换一个。

Q: 第一次念有点慢
A: 启动后要 2 秒把模型读进内存,之后就快了(0.5 秒左右)。
   常驻内存约 700MB。

   另外,如果 App 闲置了十几分钟没用,macOS 会把它占的内存换出去(能省内存),
   这时候第一次用会多花 1~2 秒读回来,属于正常现象,后面就又快了。

Q: 念出来的声音不喜欢
A: 设置里有 103 个中文音色 / 54 个英文音色,每个都能「试听」。


【卸载】

退出 App(菜单栏图标 → 退出),删掉 SnapSpeak.app 就行。
想彻底清干净,再删这两个文件夹:
  ~/Library/Application Support/SnapSpeak
  ~/Library/Logs/SnapSpeak.log
如果填过 API Key,再去「钥匙串访问」里删掉 "SnapSpeak DeepSeek"。

完全本地运行,不联网(除了你主动用翻译功能的那个请求)。
